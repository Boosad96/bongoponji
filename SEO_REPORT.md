# SEO report

The Bengali homepage, civil calendars and date converter provide server-rendered, useful content. Metadata uses the configured origin for canonical, social and sitemap URLs. The homepage includes linked WebSite and publisher Organization markup. Breadcrumbs and converter WebApplication markup remain available. Dated and filtered daily routes, pending festival pages and muhurat pages stay noindexed. The project emits no Event markup for pending dates.

On Cloudflare Pages, explicitly configured indexing is accepted only on main with the HTTPS apex `bongoponji.com`. Initial and preview builds omit SITE_URL and emit noindex metadata, an empty sitemap and a disallow-all robots file. The reserved example hostname is used for local and GitHub Actions checks. Live HTTPS, redirects, hosting and Search Console are pending.

Search intents in KEYWORD_MAP.csv are editorial hypotheses. This milestone used no measured search volume or ranking claims. Lab Lighthouse scores and real-user metrics have not been measured. Automated browser coverage validates functionality only.
