# Contributing

Use the Node version in package.json, install from the lockfile with npm ci, and run the test, check, and build scripts. Never include private reports or credentials in committed data. A source-backed religious record needs the original comparison, a method version, a verification date and explicit clearance for publication. Record disagreements per method and keep updates attributable in Git.

Use PROGRESS.md to resume and VALIDATION_REPORT.md to record what a comparison covered. When adding a page, update its title, links and sitemap eligibility together. Report a suspected incorrect date with a link, location, calendar method, affected civil date and an authoritative reference.

Run `node scripts/prepare-kolkata-sample.mjs` to recreate the three review candidates. It prints pending records and leaves the release file intact. Compare independently computed values with the references and record the result before changing a release record to VERIFIED.
